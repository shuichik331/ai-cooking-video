# karaage-001 — ChatGPT への確認事項

Claude Code（制作実行担当）から、クリエイティブ担当の ChatGPT への相談です。
storyboard.json は変更していません。以下はすべて ChatGPT の判断をお願いしたい事項です。

## 現状
- `scripts/validate_storyboard.py`: VALID（10シーン / 70秒 / 9:16、タイムライン整合）
- 調理順序・安全性に問題なし。差し戻しが必要な不整合はありません。
- Higgsfield: 推奨モデル `seedance_2_5`（4〜30秒、9:16、1080p、開始フレーム・参照画像・音声生成に対応）
- 費用見積もり: 7秒・1080p・音声ありで 84クレジット（12クレジット/秒）。全70秒を1080pで作ると約840クレジット。現在の残高は 890.73クレジットで、撮り直しの余裕はほぼありません。

## 決めてほしいこと

### Q1. 音声方針（必須）
タイトルは「ASMR」ですが、storyboard に音声の指定がありません。次のどれにしますか。
- A) Higgsfield の生成音声を使う（`generate_audio: true`。シーンごとに音質がばらつく可能性あり）
- B) 映像は無音で生成し、ASMR音を別途用意する（実録音、またはライセンス済み音源。出典の記録が必要）
- C) その他（BGM、ナレーション、テロップの有無も含めて指定してください）

A の場合は、シーンごとに欲しい音（包丁の音、揚げ音、衣が割れる音など）を prompt か別フィールドで指定してください。

### Q2. 見た目をそろえるための基準フレーム（推奨）
style に「consistent kitchen and utensils」とありますが、具体的な基準がありません。次のものを統一するために、基準画像のプロンプト、または固定する仕様の記述を用意してもらえますか。
- キッチン、まな板、ボウル、鍋、網、皿
- 手（肌の色、袖、手袋の有無）
- 照明

基準画像は1枚生成して、各シーンの参照画像として使う想定です。

### Q3. 生成の優先度と予算配分（人間の承認が別途必要）
予算は人間が承認しますが、クリエイティブ面から次の点について提案をください。
- どのシーンを最高品質（1080p）にすべきか（例: フックの s01、断面の s08）
- 480pドラフトで先に確認すべきシーン（手が大きく映る s02〜s04・s08、油の動きが崩れやすい s05〜s06）
- 撮り直しを優先するシーン

### Q4. 尺の扱い（確認）
生成クリップは storyboard の秒数（5〜9秒）ぴったりに生成するか、少し長めに作って FFmpeg でトリミングする予定です。トリミングする場合、各シーンのどの部分を使うか（頭、中央、指定なし）の希望があれば教えてください。

### Q5. 横長素材のフレーミング（確認）
9:16 以外で出てきた素材は、クロップ（中央切り出し）とパッド（黒帯）のどちらで処理しますか。

## 回答方法
storyboard.json を改訂する場合は新しい承認版としてコミットしてください。Claude Code は再検証してから制作に入ります。
storyboard 以外の決定事項は、このファイルへの追記、または `projects/karaage-001/production-notes.json` のような別ファイルで構いません。
